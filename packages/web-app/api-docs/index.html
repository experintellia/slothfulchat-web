SlothfulChat core API

The JSON-RPC API of SlothfulChat's fork of chatmail core: the pinned core commit with this repository's patches/core stack applied. Both references below are generated from that patched source on every build, so they describe the API this bundle actually runs — not the nearest published upstream release. Fork-touched items carry a 🦥 note naming the patch.

References

TypeScript reference TypeDoc over the generated client. Start at RawClient — every method hangs off it. These are the types @slothfulchat/core-wasm ships. OpenRPC spec The same methods as a browsable OpenRPC document: parameters, results and schemas, language-agnostic. Wire names, so methods are snake_case here and camelCase in the TypeScript client. openrpc.json The raw spec, for pointing tools at.

Using these types

There is no separate types package — the generated client and its declarations ship inside @slothfulchat/core-wasm:

import { BaseDeltaChat, C, type T } from '@slothfulchat/core-wasm'

Do not install @deltachat/jsonrpc-client alongside it: you would get two nominally distinct declarations of the same types, and BaseDeltaChat / yerpc.BaseTransport clash where structural typing does not save you.
